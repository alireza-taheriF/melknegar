# پلاک‌نگار — دفتر هوشمند املاکی

اپ وب پیش‌رونده (PWA، قابل نصب روی اندروید و آیفون) برای دفترهای املاک:

- **ماژول ۱ — دفتر هوشمند:** فایل‌ها و مشتری‌ها، جستجوی فوری، وضعیت فروخته‌شده/فعال، پیگیری فایل‌های قدیمی، تطبیق خودکار فایل و مشتری با درصد، متن آگهی آماده، تیم و سطح دسترسی.
- **ثبت سریع:** متن آزاد، پیام صوتی، عکس صفحه دفتر دست‌نویس (هوش مصنوعی از طریق Vercel AI Gateway) — هم در اپ، هم در ربات بله و تلگرام.
- **ماژول ۳ — خدمات:** سفارش عکاسی/ریلز برای فایل‌ها و فرم عمومی «بازدید فنی قبل از خرید» برای خریداران، با پنل مدیریت سفارش‌ها.
- **پنل مدیریت پلتفرم:** ساخت دفتر برای مشتری جدید، کاربران، ربات‌ها، سفارش‌ها.

## معماری

- فرانت: HTML/CSS/JS خالص (بدون build)، RTL، فونت وزیرمتن، Service Worker.
- بک‌اند: یک Vercel Function (`api/index.js`) بدون وابستگی جز `@vercel/blob`.
- ذخیره‌سازی: هر سند با AES-256-GCM رمزنگاری می‌شود؛ پیش‌فرض Vercel Blob خصوصی، و اگر Upstash Redis به پروژه وصل شود خودکار روی آن مهاجرت می‌کند.

## امنیت

رمز عبور با scrypt، نشست با کوکی `__Host-` امضاشده (HttpOnly، Secure، SameSite=Strict)، محافظت CSRF (Origin + هدر سفارشی)، محدودیت نرخ و قفل حساب، جداسازی کامل داده دفترها، CSP سخت‌گیرانه، رمزنگاری داده در حالت ذخیره، وب‌هوک ربات با کلید مخفی تصادفی.

## اجرا روی سیستم

```bash
SEED_DATA=$(node scripts/make_seed.js '{"demo":true,"tenant":{"name":"دفتر نمونه"},"users":[{"name":"مدیر","username":"admin","staff":"superadmin","password":"..."}]}') npm run dev
npm test
```

متغیرها: `APP_URL`، `SEED_DATA` (اولین راه‌اندازی)، `BLOB_READ_WRITE_TOKEN` یا `KV_REST_API_URL`/`KV_REST_API_TOKEN`، اختیاری `MASTER_KEY` و `AI_GATEWAY_API_KEY`.
